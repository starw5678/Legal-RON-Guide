# Legal RON Guide

A practical starter guide for launching a Texas remote online notary (RON) workflow.

This project is a React web app scaffold that explains:

- What RON is
- What a Texas notary needs before offering online notarizations
- Suggested tools and platforms
- Startup checklist
- Basic cost planning
- Client workflow
- Common mistakes to avoid

## Quick Start

```bash
npm install
npm run dev
```

## Scripts

- `npm run dev` - start the Vite dev server
- `npm run build` - build the production app
- `npm run preview` - preview the production build

## Disclaimer

This app is for educational planning only. It is not legal advice. Always verify current Texas Secretary of State rules and platform requirements before offering RON services.
